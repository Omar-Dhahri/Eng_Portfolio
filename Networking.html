Enterprise Video Surveillance Infrastructure — Large Supermarket Rack Deployment

Server Rack · VMS · PoE Network — Dell PowerEdge R750xs / Mikrotik / Dahua, 2026

IT Networks · Enterprise Server · Video Surveillance

Full-store surveillance coverage for a large supermarket is not a single device installation; it is a small data centre. Dozens of cameras recording continuously generate a sustained storage and processing load that a consumer NVR was never designed to handle, so the project called for genuine enterprise hardware, assembled, wired, and configured to run reliably around the clock.

At the centre of the build sits a Dell PowerEdge R750xs rack server, configured with a mix of 1.2TB SAS and 16TB SATA drives to balance fast indexing storage against the long-term capacity needed for full-store recording retention. The server was installed with Windows Server as the platform for the video management software, with the operating system configured, patched, and hardened before the VMS application was installed and connected to every camera on the network.

The network layer supporting the server was built from two Dahua PoE switches and a Mikrotik router handling routing and network segmentation between the surveillance VLAN and the rest of the store's infrastructure. CAT6 cabling was pulled and terminated from the rack to every camera position across the supermarket floor, covering dozens of cameras providing full-store coverage; every run labelled and documented at both ends as part of the cabling schedule. The PoE switches deliver both data and power to each camera over the same cable run, simplifying the installation considerably compared to running separate power circuits to each mounting point.

Power continuity for the entire rack is handled by a dedicated UPS unit, protecting the server, switches, and router against outages and short power interruptions that would otherwise interrupt continuous recording. All active rack equipment, server, switches, UPS, and patch infrastructure, was mounted using vertical cable management arms throughout the rack height, keeping the patch cabling organised and serviceable rather than left loose inside the enclosure.

Once the hardware was racked and wired, the configuration phase brought the system to life: server network settings, the VMS application, and every individual IP camera were configured in sequence; assigning addressing, registering each camera into the VMS, setting recording schedules, and verifying live feed and playback quality from each one before the system was signed off. Basic cybersecurity checks were applied across the server, switches, and router before handover, including default credential changes and access restriction on management interfaces. The project closed with full technical documentation and a completed service report, and the corresponding ticket closed in the company's field management system.

Network Infrastructure Extension — Heavy Metal Forming Industrial Facility

Fibre Optic Backbone · Structured Cabling · Media Conversion — CAT6 / SFP, 2025

IT Networks · Industrial · Fibre Optics

Extending a network in a heavy metal forming facility is a problem that begins long before a cable reel is opened. The production floor spans hundreds of metres, overhead cranes carry coils of raw steel on rails that run the full length of the building, rolling mills and forming machines generate significant electromagnetic interference, and the distances involved simply exceed the reliable range of copper Ethernet. The solution is not more cable; it is a different kind of cable.

This project involved the extension of an existing network infrastructure across the active production floor of a large metal forming plant; a facility where steel coils, bar stock, and sheet material are processed continuously by heavy machinery under overhead gantry cranes. The existing network reached the edges of the production area; the brief was to extend it into the floor itself, reaching switch distribution points deep within a space where copper cabling would be degraded by electromagnetic noise and limited by distance.

The backbone of the extension was built on fibre optic cabling, pulled from the existing network termination points and routed through the facility to new wall-mounted switch enclosures installed at strategic distribution points across the floor. At each enclosure, a NextWave media converter (10/100/1000Base-TX to 1000Base-FX) was fitted to bridge the fibre backbone to the local copper Ethernet ports of the switch; the SFP fibre port on the converter accepting the incoming optical signal and presenting a standard gigabit RJ45 interface to the switch and downstream devices. SFP transceivers were selected and inserted to match the fibre type and link distance at each point, ensuring the optical budget was met across the full run before any connection was finalised.

From each enclosure, copper structured cabling was pulled to the local access points and devices that the extension was designed to serve; each run routed carefully to avoid the EMI-heavy zones around the forming machines and crane rail infrastructure. The Rittal-style main rack, already housing the plant's Siemens automation hardware, Dell server, and UPS, received the new network extension connections cleanly at its existing switch layer without disruption to the live automation network.

Every link was tested and measured after termination; optical power levels at each fibre run, copper continuity and signal quality at each patch point, and end-to-end connectivity confirmed from each new switch enclosure back to the core. Basic cybersecurity checks were applied to each new switch before it was placed into service, covering default credential changes and access port restrictions, to maintain the security posture of a network that sits alongside active industrial control systems.

Solar-Powered Cloud Surveillance System — Off-Grid Installation & Field Maintenance

IP Camera · Solar Power · Cloud Recording — Steca Solsum 1010 / NetBox, 2024–2026

IT Networks · Surveillance · Solar Power

Some surveillance requirements exist precisely where infrastructure does not. No mains power. No nearby network cabinet. Just open terrain, a security need, and the expectation that the camera will be recording and uploading to the cloud regardless of the time of day or the season.

In 2024, we designed and deployed a fully autonomous solar-powered IP surveillance station for a client with exactly this requirement. The system integrates three layers that must work together without human intervention: power generation and storage, local electronics management, and cloud-connected video recording.

The photovoltaic panel mounted at the top of the mast serves as the primary power source during daylight hours, simultaneously powering the camera and the NetBox cloud recorder while channelling surplus energy into a 12V sealed lead-acid battery housed in the weatherproof enclosure below. At dusk, the Steca Solsum 1010 solar charge controller detects the drop in panel output and automatically switches the load to battery power, ensuring the camera remains operational throughout the night without any manual intervention. At dawn, the cycle reverses; solar takes over, the battery begins recharging, and the system returns to its daytime configuration autonomously.

The network side of the installation was equally deliberate. The camera was configured with a static IP address and connected to the NetBox cloud recording unit via a local TCP/IP link; the NetBox handling cellular or network uplink to the company's cloud storage platform so that footage is accessible remotely in real time without requiring on-site NVR hardware. All device addressing, stream parameters, and recording schedules were set and verified before the enclosure was sealed and the system handed over as live.

In 2026, the client reported a system outage; the camera had gone dark overnight and was not recovering during the day. Working under time pressure with a surveillance gap already open, the team drove to site and began a structured fault-finding process. Voltage measurements across the power circuit quickly pointed to the charge controller; the Steca Solsum 1010 was producing no output to the load terminals despite the panel generating correctly, confirming an internal controller fault rather than a panel, battery, or wiring issue. The faulty unit was removed from the enclosure in the field, a replacement controller was fitted and wired, and the system was brought back online; camera reconnected, cloud recording confirmed active, and the circuit verified across all three terminals before the enclosure was closed. The maintenance visit was closed with a completed service report and ticket logged in the company's field management system.

IT Networks · Smart Infrastructure · Field Service

Speed limit signs tell drivers what the limit is. Radar speed warning displays tell them what they are actually doing — and that difference, in the seconds before a driver decides to brake, is where road safety interventions have their most immediate effect.

The DHI-ITACS-024SA-JB operates on a 24.150 GHz radar centre frequency, detecting vehicle speeds from 5 to 199 km/h with an accuracy rating of ±1 km/h, and displaying the reading in real time on a large-format LED matrix panel visible from a significant approach distance.

Every panel was tested and verified before installation; the internal electronics were inspected, the LED display matrix powered and validated, and the radar detection function confirmed to be operating correctly. Working at height on an active road required strict adherence to safety procedures throughout; ladder positioning, traffic awareness, and two-person coordination were maintained at every installation point.

The completed installations deliver a permanent, automated speed awareness tool at each road entry point; one that requires no operator presence, responds to every vehicle that passes, and provides drivers with the one piece of information most likely to change their behaviour in the moment.

Full-Building IT Infrastructure Deployment — 8-Floor Commercial Office Tower

Structured Cabling & Network Infrastructure — CAT6 / Rack Servers / Patch Panels, 2025

IT Networks · Structured Cabling · Field Service

When a building has eight floors and no network infrastructure at all, the work does not begin at a screen. It begins at the ground floor with a cable reel, a plan, and the full weight of knowing that every decision made in the walls today will determine how the building communicates for years to come.

As lead technician on this project, I coordinated a small team to design and deploy the complete IT infrastructure of a commercial office building from the ground up, floor by floor, across all eight levels. The scope covered every layer of the physical network: cable pulling, conduit routing, rack installation, patch panel termination, labelling, and connectivity validation before handover to the client.

The cabling backbone of the project was CAT6 structured cabling, pulled through corrugated conduits and metal cable trays routed along ceilings and down partition walls throughout each floor. Every run was planned to avoid interference with the building's electrical and plumbing routes, and every conduit exit point was positioned ahead of the partition wall finishing, so that the cable infrastructure was embedded cleanly within the building structure rather than surface-mounted as an afterthought. The photos tell the story of that in-wall phase; open metal stud frames, corrugated conduits bundled and labelled at junction boxes, cable runs descending through floor penetrations to the next level down, and ceiling tray sections packed with data and power feeds moving across the open slab before partitioning closed everything in.

Each of the eight floors received its own dedicated rack server enclosure, housing a patch panel terminating all horizontal cable runs from that floor's outlet points. This per-floor distribution design keeps fault domains contained, makes future moves and adds straightforward, and gives the building a fully managed network architecture rather than a centralised star topology that would have required significantly longer cable runs from a single point.

Every cable run was labelled and documented at both ends throughout the installation, not at the end of it; a discipline that saved significant time during the termination and testing phase. Connectivity was validated at each floor before the team moved on, catching any physical layer faults while the walls were still accessible. The project was completed with full technical documentation covering the cabling schedule, rack layouts, patch panel assignments, and floor-by-floor test records, handed over as part of the building's IT commissioning package.

IP Video Intercom & Access Control System — Modern Kindergarten

IP Intercom · PoE Network · Electromagnetic Lock — Dahua VTH2611L-WP / DHI-VTO6521H, 2024

IT Networks · Access Control · IP Intercom

A kindergarten has one security requirement that overrides every other: only the right people get through the front door. Every parent dropping off a child needs to be identified before entry is granted, every room needs to remain in communication with the reception, and the staff needs to be able to see, speak, and respond from anywhere inside the building without needing to walk to the entrance every time a visitor arrives.

This project delivered exactly that; a fully networked IP video intercom and electronic access control system across a modern kindergarten, integrating ten indoor room monitors, a smart entrance door station, and an electromagnetic door lock into a single coherent communication and security infrastructure.

At the entrance, a Dahua DHI-VTO6521H Apartment Door Station was installed as the visitor-facing unit; a flush-mounted IP panel combining a wide-angle camera, a colour touch display, a numeric keypad for PIN entry, and a built-in card reader for RFID-based access. The door station connects over the local IP network and communicates simultaneously with all ten indoor monitors, allowing any authorised staff member in any room to see the visitor, speak with them, and remotely release the door from their monitor screen. Entry is controlled by a DC 12V electromagnetic lock wired directly to the door station's LOCK1 output terminal; the lock holds the door closed under power and releases only when a valid access event is confirmed, whether by PIN, RFID card, or remote monitor release.

The ten Dahua VTH2611L-WP Wi-Fi Indoor Monitors were mounted in each room throughout the kindergarten; each unit offering a 4.3-inch colour touch screen for live video display, two-way audio communication with the door station, group call capability across all monitors simultaneously, alarm integration, and IPC surveillance feed access. All monitors are Standard PoE-powered, which simplified the installation significantly; a single CAT5e FTP run to each monitor location carries both data and power, eliminating the need for separate electrical feeds at each room position.

The network backbone was built around a 16-port PoE switch added to the existing rack server in the building, providing powered ports for all ten monitors and the door station from a single managed switch. CAT5e FTP structured cabling was pulled from the rack to every device position throughout the building, with cable moulures used for clean surface routing in finished rooms. All devices were configured over TCP/IP after installation; IP addressing, door station pairing, monitor registration, call group assignments, and lock output parameters were set and verified before the system was handed over to the kindergarten staff.

Following handover, user support and technical assistance was provided to the staff directly on site; walking them through the daily use of the monitor screens, the door release procedure, and the RFID card registration process, ensuring the team was confident and independent with the system before the technicians left.
