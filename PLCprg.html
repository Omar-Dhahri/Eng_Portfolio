Ejection Sorting Station — Structured Text (Allen Bradley)

Allen-Bradley · Structured Text · Factory IO + CCW Simulation

Intermediate · Discrete Automation

Industrial sorting systems are where control logic meets real-world chaos: variable object sizes, imperfect sensor readings, and strict timing constraints that must still produce deterministic results. This project was designed to replicate that environment as closely as possible using a fully simulated ejection sorting station built around Allen-Bradley Structured Text programming.

The system processes moving boxes on a conveyor using diffuse photoelectric sensors to detect object size and position. Based on this detection, the PLC executes a decision-making sequence that routes each object to the correct output lane using an ejection mechanism. What makes this system more than a basic sorting demo is the control architecture behind it: a structured, state-driven logic model written entirely in Structured Text, designed to behave like a real industrial controller rather than a simple classroom exercise.

A complete operator panel was integrated into the logic design, including Start/Stop commands, emergency stop with reset logic, status indicators, and real-time production counters. Each signal was mapped into a clear operational state machine, ensuring that the system always remains in a defined condition — whether running, paused, faulted, or reset. Special attention was given to safety conditions: emergency stop overrides, restart sequencing, and controlled reinitialization after faults were all explicitly handled in the program flow.

The logic was developed and validated using Factory IO as a real-time 3D industrial environment, connected to an Allen-Bradley control simulation through CCW (Connected Components Workbench). This setup allowed full testing of conveyor dynamics, sensor triggering, and actuator response under realistic timing conditions. Every box detection, every ejection decision, and every counter update was visually verified in a live virtual plant environment — mirroring how modern automation engineers validate discrete manufacturing systems before deployment.

Automated Warehouse — Storage Logic & Path Planning

S7-300 · Ladder Logic · TIA Portal + Factory IO Simulation

Advanced · Smart Warehousing

Modern automated warehouses are no longer limited to simple conveyor transport systems. They operate as highly coordinated real-time material handling environments, where storage allocation, retrieval sequencing, motion synchronization, and positional tracking must all function simultaneously without interrupting operational throughput. The engineering challenge is not only moving products — it is maintaining deterministic control over an entire logistics flow while the system continuously evolves in real time.

This project was engineered as a fully automated warehouse storage and retrieval system using Ladder Logic on a Siemens S7-300 PLC. The control architecture managed the complete warehouse lifecycle: pallet intake, storage assignment, positional indexing, rack navigation, retrieval requests, and conveyor coordination across multiple transport zones. Unlike linear automation sequences, the system required dynamic decision-making based on positional availability, routing constraints, and transport-state synchronization.

The automation strategy relied on a structured path-planning and indexing methodology. Every storage location was represented through coordinated positional logic, enabling the warehouse crane and conveyor system to navigate accurately between rack levels and transport points. Motion permissions, storage validation, and retrieval authorization were continuously monitored through synchronized interlock conditions to guarantee stable transitions between operational states while preventing undefined movement sequences or storage conflicts.

Particular attention was dedicated to system synchronization and operational reliability. Conveyor occupancy states, transfer authorization, positional reset validation, and rack-access timing were integrated directly into the PLC logic to maintain deterministic warehouse behaviour under continuous operation. Sequential verification conditions ensured that no transport or retrieval command could execute unless every prerequisite state had been confirmed, significantly reducing the risk of indexing errors, transport overlap, or unstable transfer conditions.

The entire warehouse environment was developed and validated using Factory IO connected live to PLCSim, executing the actual compiled S7-300 control program in real time. This virtual commissioning workflow reproduced a fully operational smart warehouse environment where conveyors, storage racks, transfer systems, and positioning mechanisms responded directly to PLC outputs. The simulation enabled continuous validation of path planning behaviour, storage sequencing, transport synchronization, and retrieval accuracy before any physical deployment stage — reflecting the same engineering methodology used in modern industrial intralogistics and warehouse automation projects.

The control architecture was designed to classify products dynamically according to physical dimensions detected through coordinated sensor arrays, then execute the appropriate routing sequence while preserving uninterrupted conveyor throughput and stable material handling conditions.

Pick & Place — Sensor-Driven Conveyor Automation

S7-300 · Ladder Logic · TIA Portal + Factory IO Simulation

Starter · Material Handling

In industrial production environments, moving a product from one location to another sounds simple — until timing, synchronization, and motion coordination become part of the equation. A pick-and-place system is not just about detecting an object and activating a mechanism; it is about ensuring every movement happens at exactly the right moment, without collision, missed detection, or unstable positioning.

This project focused on developing a fully automated sensor-driven pick-and-place sequence using Ladder Logic on a Siemens S7-300 PLC. The system was designed to detect incoming boxes on a conveyor, stop them precisely at the transfer position, activate the pick mechanism, move the item to a target location, and safely release it before restarting the conveyor for the next cycle.

The engineering challenge was not simply making the actuator move — it was coordinating every stage of the sequence so the system behaved like a real industrial material-handling cell. Sensors had to confirm object presence before motion was allowed, conveyor movement needed to pause during transfer operations, and interlocks were implemented to prevent overlapping commands between conveyor and actuator states. Without proper synchronization, the result could easily become dropped products, actuator collisions, or unstable transfer timing.

The complete automation sequence was developed and validated inside Factory IO, connected live to PLCSim running the actual compiled S7-300 program. This created a fully interactive virtual production cell where sensors, conveyors, and pneumatic movements responded in real time to PLC outputs. Using simulation made it possible to test positioning accuracy, sequence transitions, and actuator timing repeatedly before any physical hardware deployment — the same virtual commissioning approach widely used in modern industrial automation engineering workflows.

Filling Tank — Timer-Based Process Control

S7-300 · Ladder Logic · TIA Portal + Factory IO Simulation

Starter · Process Control

Every industrial process that moves fluid through a system shares a common challenge: time. Not just how long something takes — but what happens when it takes too long, or not long enough. This project was built around that exact problem.

The objective was to design a fully automated fill-and-drain cycle for an industrial tank, controlled entirely through timed sequences in Ladder Logic on a Siemens S7-300 PLC. The logic had to handle the complete lifecycle: open the inlet valve, monitor fill duration, close it at the correct level, hold, drain on schedule, and wait for the tank to empty before the next cycle could begin — all without a single manual input once the sequence was started.

But the more interesting engineering was in the edge cases. What if the fill timer expires and the level hasn't been reached — is that a sensor fault or a supply failure? What if the drain cycle is still running when the next fill command arrives? What if power is restored mid-sequence? Each of these scenarios was designed into the logic as explicit states, with safety waits and interlock conditions preventing the system from entering an undefined or dangerous condition.

The entire project was developed and validated inside Factory IO — a professional-grade 3D process simulation platform that renders a live virtual plant responding to real PLC outputs in real time. Connected to PLCSim, the simulated S7-300 ran the actual compiled program while Factory IO provided the physical feedback: valves opening, tanks filling, drain pumps activating — all visible, all measurable, all testable without a single piece of real hardware. This is exactly how modern automation engineers validate control logic before it ever touches a real process — and it meant every edge case, every timeout scenario, every safety interlock could be stress-tested safely and repeatedly until the logic was right.
